# Verify a visible Slides change

Use this loop when an authorized edit affects text flow, geometry or styling. No edit count is required.

1. Confirm the requested slide scope. Read live object IDs and current geometry, then inspect the rendered thumbnail before deciding what to change.
2. A tool success, image pointer or URL is not proof of pixel inspection. Use the host's supported image viewing/retrieval path; if unavailable, report the visual verification limit. Structural verification remains useful but does not establish rendered quality.
3. If the slide already satisfies the requested outcome, finish with a read-only check. Otherwise identify a concrete defect and batch a coherent correction, preserving real content and the selected layout/destination.
4. Use the correct shape/line/image request family. Include fresh revision/write control when exposed. Prefer geometric repairs to compressing text.
5. Read the changed content/geometry and inspect a fresh render after each write. Check clipping, overlap, padding, crops, hierarchy, repeated styles and regressions relevant to the change.
6. If a defect remains, refresh live structure before the next write. Stop when the outcome is verified or further edits stop improving it; explain remaining limitations. Never add writes to satisfy a pass quota.

For decks, maintain a requested-slide coverage checklist. Pilot repeated structural fixes on a representative slide before an authorized batch. Use the focused visual-iteration or template-surgery skill when its conditional guidance helps.
